# Project management

Use this folder for research-facing material that should guide the project but is not itself part of the manuscript.

- `research_notes.md` preserves the existing planning notes.
- Add a dated decision log when changing theoretical claims, model assumptions, estimands, or data definitions.
- Maintain a claim-to-evidence matrix: each theoretical proposition should link to its model mechanism, experiment, outcome, figure/table, boundary condition, and manuscript section.

For this study, the most important audit trail is the connection between the theoretical account of AI recruitment feedback and the ABM implementation that generates each reported result.
