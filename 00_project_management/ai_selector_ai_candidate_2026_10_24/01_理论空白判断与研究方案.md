# AI评价AI：有研究价值，但需要把问题再收窄一层

## 1. 我对你想法的理解

你不是只想问“AI招聘有没有偏见”，而是想把选拔看成两个具有调整能力的系统之间的关系。

情境A：真正应聘的是人，但人将简历、应答或求职决策的一部分交给AI；组织也将筛选的一部分交给AI。此时被直接评分的是AI介入后的材料或行为，最终雇佣对象仍是人。

情境B：真正被采购、分配任务或续约的是AI代理。其能力必须界定为某个模型、工具、记忆、工作流和预算的组合，不能只用模型品牌代替。

两种情境可以共享一个理论问题，但不能共用未经验证的行为假设。尤其不能用AI代理实验直接声称人类求职者会如何学习。

双向反馈要分别成立：

```text
评价规则/反馈 → 人或代理调整所用AI、策略、能力投入 → 新一轮提交与工作结果
       ↑                                                   │
       └──── 组织依据哪些数据、由谁授权调整评价规则 ──────────┘
```

只是重新评分，属于结果变化；组织改提示词、评分量表、模型选择或审计规则，才是评价制度调整。固定模型多调用几次，不等于模型权重学习，更不等于双方共同进化。

## 2. 哪些说法已经不能作为空白

| 想提出的创新 | 已有直接近邻，详见证据清单 | 本轮判断 |
|---|---|---|
| AI会偏好自身生成的内容 | Panickssery等；Xu等 | 不能作为首次发现 |
| 写作AI与筛选AI的组合改变招聘结果 | Xu等；Ebling等 | 很直接的重叠 |
| 求职者用AI，招聘方再改变处理方法 | Cohen等Two Tickets | 不能说反向应对无人研究 |
| AI让能力信号更好看但更难辨认 | Cowgill等；Cui等 | 已有理论和经验研究 |
| AI代理会竞争、训练、积累声誉 | Chiu等AI-Work | 动态与技能投资本身不新 |
| AI代理反复交易，评价者也受市场反馈影响 | Diagon | 双向影响和重复互动不新 |
| 被评价模型与评价标准共同更新 | EvoRubrics；ARCO；J-Zero | 计算机领域已有直接工作 |
| 分数升高不等于实际质量提高 | 奖励过度优化研究；Kim等 | 不能把Goodhart效应重新命名为理论贡献 |
| 给AI代理做可核验资质与声誉记录 | LEGIT | 仅加“数字员工证书”不够 |

招聘的相互适应更早已有信号博弈框架。因此，新稿必须解释AI改变了哪一个具体条件，而不是把“申请人”和“招聘者”换成两个LLM。[Bangerter等，2012](https://pubmed.ncbi.nlm.nih.gov/22040263/)

特别警惕三种概念偷换：同模型优势不一定是自我识别；自我偏好不一定意味着实际能力较差；文字不同不等于能力不同。标签效应、文风、一般写作质量和真实任务互补性必须拆开。

## 3. 优先候选问题：选拔体系究竟在挑选能力，还是在塑造AI的选择？

暂定题意：**为通过选拔而选择AI，与为完成工作而选择AI，何时一致，何时冲突？**

这比“AI喜欢自己”更接近你们原来的反馈制度主线：评价不只是观察人或代理，还可能改变他们随后采用的生产工具。

### 3.1 要挑战的具体假设

不能笼统说“既有理论都把AI使用当作外生”。例如Cowgill等已在扩展中内生化AI使用。更精确的切入点是：其主模型招聘方的事后收益对应人的专业能力，而不是AI对材料的增强能力，见正文§2.1.4。我们拟考察另一种工作条件：**入职后仍允许并依赖AI，实际产出取决于人/代理与AI配置的任务互补性。** [原文](https://pubsonline.informs.org/doi/10.1287/mnsc.2024.07027)

我们的新增设定不能只是“使用AI”，而应是：候选人或代理可以在不同配置间选择；有些配置更容易被当前评价器接受，另一些配置更适合完成实际工作；评价方还可能根据反馈调整制度。

这里的“评价兼容性”只是工作性概念，须操作化为：控制事实、任务质量等以后，某个生成配置对特定评价器仍有的相对得分优势。它不是已经建立的新构念。

### 3.2 拟研究的机制链——以下全部是待检验假说

评价器的差异化回报 → 学习何种AI配置更容易入选 → 有限预算在评价适配、工作工具、真实训练之间重新分配 → 候选群体的配置与能力组成变化 → 组织观察到的绩效/材料再影响下一轮制度。

值得检验的不是“一定有害”，而是一个方向可能翻转的命题：

- 当选拔时用的AI能力在工作中能延续、且实际任务需要相同协作方式时，适配评价可能同时改善生产匹配。
- 当评价优势主要来自表达或来源线索、工作任务依赖另一套能力或工具时，适配评价可能挤出更有生产价值的投入。
- 当候选人能在申请与工作时低成本换工具，所谓“评价—生产冲突”可能显著减弱。因此，切换成本和配置承诺必须被观测或操纵，不能默认存在。

真正的理论增量，应当是识别**评价兼容性与生产互补性的关系、可切换性和反馈治理共同决定投入方向**；不是再证明多模型存在得分差异。

### 3.3 为什么现在还不能宣布空白成立

Ebling等直接处理模型组合与招聘偏好；Diagon已研究同模型家族偏好和重复交易。另有Liu《When Better AI Reveals Less》从摘要看已涉及企业选AI质量与监督能力识别，必须读全文；Wang的Research Policy论文也涉及生产—评价张力，但本轮只核对元数据及公开摘要线索。它们限制了“首次将生产和选拔放在一起研究”的说法。

所以本方向目前是：**可操作、值得优先做近邻全文审查和小型先导检验；理论新意尚待确认。** 不宜现在就写“现有研究忽略了……”。

## 4. 第二候选问题：被选拔者的适应，何时改进评价，何时使标准偏向自身？

暂定题意：**当双方都能调整时，谁提供的反馈决定什么算“有能力”？**

我们可以比较两类组织制度，而不是笼统比较“静态/动态AI”：

1. 组织主要根据已有评价器认可的材料、历史入选者或其评价数据来修订规则。
2. 组织根据独立工作结果，并用一定比例未入选替代项的可核验测试来修订规则。

两个制度中，候选端都可以适应；差别在于评价端接触到的纠错证据和组织授权。**没有明确的数据获取渠道，就不能假定组织知道落选者实际绩效。** 受控任务中可统一执行；真实招聘中需要额外实验、审计样本或识别设计。

可检验的问题是：候选端策略变化，是否让第一类制度越来越确信自己的判断，却不能提升外部任务表现；第二类制度是否在某些条件下产生共同能力改进。需要允许反例：适应可能揭示真实需求，内部反馈也不必然失效。

本方向与选择性标签、执行性预测、奖励过度优化、ARCO/EvoRubrics等高度邻近。**“双方更新标准”本身不是增量。** 若要保留，必须解释组织为何选择不同反馈来源，谁承担审计成本，谁拥有改规则的权力，以及因此出现什么新结果。尚未完成这些理论文献的穷尽核查，优先级低于上一方向。

## 5. 两种情境怎么安排

| | 人用AI应聘 | 直接选拔AI代理 |
|---|---|---|
| 研究对象 | 人—AI组合；最终雇佣的是人 | 特定配置的代理及其运营者 |
| 谁调整 | 人选择工具、验证输出、训练；AI执行被授权操作 | 运营者或代理在明确权限内调整工具、策略、记忆等 |
| 能力基准 | 与目标岗位对应的人独立表现或人—AI实际工作表现，须事先选定 | 固定条件下任务成功率、质量、成本、可靠性及迁移表现 |
| 主要风险 | 把材料润色等同造假，或把LLM行为当作人的反应 | 把模拟技能增长当作真实模型能力提升，把采购等同劳动关系 |
| 建议定位 | 优先主场景：更能衔接原有招聘反馈问题 | 并行核查，后续可作对照研究，不默认只是外部效度补充 |

我的建议不是把两种情境立即塞进一篇论文。先用同一个问题比较二者，再选择能提供最强证据的一种作为主场景。

## 6. 最小研究路径：先验证关键关系，再决定是否需要ABM

### 第一关：把“分数”“能力”“配置”分开

用同一事实档案/任务基础，交叉生成配置和评价器；盲化来源、随机化顺序，检查长度、风格、质量与事实保持。另设可执行结果或独立、盲化的工作样本评价。至少覆盖多个模型家族；固定具体模型版本和调用条件。

同一模型的高得分不能自动记为偏见。只有相对预先确定的、与目标工作相关的外部准则，才有可能区分正当匹配和不相关偏好。人的写作也是岗位核心工作时，表达质量未必应被控制掉；研究构念必须先定。

### 第二关：让选择真的发生

允许参与者或代理在固定资源下选择配置、调整方案。区分有反馈/无反馈，记录其选择是否变化，并执行实际任务。若想声称影响人的技能投资，需要相应的人类纵向证据；纯LLM实验只能说明受控代理行为。

如研究评价端反向变化，可设计“候选端能否调整 × 评价规则能否调整”的四种状态，另外明确规则更新的数据来源。不要把微调、上下文记忆、改量表和换模型混成同一种学习。

### 第三关：识别组织机制

控制总预算，比较评价/生产工具可自由切换与需要持续使用同一配置，或比较不同纠错证据。制度处理的独立实验单位通常是独立市场/组织运行；同一档案的多次API调用不是多个独立应聘者。推断应考虑档案、任务、模型和重复运行的相关性，不能沿用旧ABM的种子数量当样本量。

### 第四关：再决定方法

若关键兼容性关系在受控试验中不存在，先收缩或放弃该机制，不能在ABM里设一个“偏好参数”把它造出来。若关系存在且动态选择重要，再搭最小模型研究长期反馈，抽象哪些行为必须讲清楚。当前不需要改现有锁定模型。

## 7. 停止或改题条件

- 最邻近全文已完整研究同一配置选择、双向反馈和组织后果：改定位，不争“首次”。
- 得分差异由岗位相关质量完全解释：不能保留“评价偏见”的原解释。
- 候选端不改变选择或投入：反馈制度机制尚不成立。
- 工具能无成本自由切换且不影响生产：不能声称选拔锁定生产配置。
- 外部工作表现随分数同步改进：不是迎合失败，应考虑生产性匹配解释。
- 只有固定生成器与固定评价器的矩阵差异：目前只是审计研究，还不是动态组织理论。

## 8. 本阶段结论

**值得研究，但应从“AI对AI”转为“评价制度如何塑造人/代理的AI配置选择，以及这种塑造是否服务于实际工作”。** 第一候选较适合优先推进；第二候选保留为反馈治理扩展，但重叠更多。

本轮验证的是近邻存在、部分原文机制以及设计可操作性；没有验证拟议命题，也未证明研究空白已被排他确认。下一步需要团队决定主场景，并先审查最直接的几篇全文，而不是立即改稿、搭大模型或确定投稿期刊。
