# 检索范围、证据边界和交接

## 本轮真正做了什么

采用academic-search及orgsci-paper-decomposition的检索和机制对照规则。主问题由用户明确为两类情境均考虑；不限定OrgSci，以理论缺口优先，跨招聘测评、管理、经济学与AI研究。

### API部分：27次独立请求，不含缓存复用

- OpenAlex：6组查询，每组仅首页8条，上限48条原始发现结果，存在大量重复；时间筛选2021-01-01至2026-10-24。不是48个独立研究。
- Crossref：7次精确DOI查询，其中6次成功；ACL论文那次返回429，无Retry-After，本轮未重试，改核官方ACL页面。
- arXiv：13次本机Python HTTPS请求均遇到证书链验证失败。没有关闭TLS校验，也不把本机失败解释为论文不存在或需要付费；改用网页检索工具核对原站。
- PMLR：1次正式论文页请求成功。

实际请求URL、UTC时间、状态和原始响应在query_log.json与search_records/中。缓存重用不另计一次检索。网页工具的搜索和正文核查不在该27次API请求中。

六组实际OpenAlex查询：

1. AI self preferencing algorithmic hiring
2. LLM hiring strategic manipulation model choice
3. LLM judge generator co evolution
4. AI agent labor market evaluation reputation
5. LLM judge reward overoptimization
6. algorithmic monoculture hiring

网页补查实际使用过的方向包括AI self-preferencing/hiring、LLM-as-a-judge self-preference、generator–judge co-evolution、strategic LLM hiring、AI-agent labor markets、reward overoptimization，以及模型选择、生产互补与招聘信号等。追查Xu、Ebling、Cohen、AI-Work、Diagon等原始来源；没有把新闻、社交媒体或自动摘要站当成论证依据。Liu摘要从Crossref原始注册记录获得，不采信自动摘要站对全文模型的扩写。

### 输出清单与去重

- records.json：7条成功API/正式页面元数据记录。
- manual_sources.json：13条原始页面核查记录及固定核查时间；含论文版本、证据层级说明。
- combined_records.json：20条可复用元数据记录；不是20篇全文精读。
- validation.json：20/20通过，0错误、0警告。这只说明格式和来源字段合规，不证明理论空白成立。
- deduplicated.json：20条保留，1组同题名候选。人工判定为Xu等AIES短文/arXiv完整稿版本关系，对应19个研究身份。没有把不同版本的数值拼成一个结果。
- references.bib：由核对后的元数据生成；未填造未知DOI、日期或引用次数。

没有批量下载PDF、没有访问付费墙绕过渠道、没有运行任何LLM招聘实验。记录中的开放PDF入口不代表已经下载或核验了PDF文件。

## 不能声称的完成程度

这是一轮有界的近邻和反证检索，不是穷尽性系统综述。不覆盖所有数据库、语言、引用网络或未公开工作。对于只有摘要的论文，不判断其附录没有某种机制。预印本不自动当正式同行评议论文；接收状态仅在原站报告时注明。

对于主候选，我们查到清楚的直接重叠，也形成了较窄、可检验的问题；但没有获得“所有近邻均排除”的证据。未补齐三篇高重叠全文之前，不宜公开宣称理论新颖性已确认。

## 交接六项

1. **理论问题**：AI选拔如何改变人/代理所用AI的配置与投入？这种适应何时促进真实工作，何时只促进被评价？评价方又依据谁的反馈调整制度？
2. **来源指针**：02_近邻证据与必读清单.md内的原始页面、combined_records.json及原始API响应；项目背景来自根README、research_notes及当前复现档案README。
3. **已核实/推断**：已核实直接近邻的存在及部分关键机制；选题排序是分析判断；两条机制链与可能的方向翻转是未检验假说，没有模拟或现场结果。
4. **文件变化**：仅新增本目录的判断、证据、检索和元数据文件；不修改02_literature既有精读卡、稿件或04_computation。原来的gap_assessment_2026_10_24目录保留。
5. **剩余不确定性**：最邻近全文与后续版本覆盖尚不完全；现实参与者是否会因选拔而换AI/改变投入尚待检验；组织如何获得外部表现反馈须具体化。
6. **下一决策**：团队选择主场景。建议先以人—AI求职组合为主，直接AI代理作并行候选；优先补齐Ebling、Liu、Wang三篇全文，之后再决定是否做先导实验。暂不定期刊、不启动大规模仿真。

本轮未commit、未push。该请求不含新的推送授权。现有未跟踪文件均保留。

## 复核命令

在仓库根目录用可用的Python/Node运行。此处的python/node指向本机可用运行时；本轮实际使用Codex bundled Python与Node。

```powershell
python -X utf8 00_project_management/ai_selector_ai_candidate_2026_10_24/tools/search_neighbors.py
python -X utf8 00_project_management/ai_selector_ai_candidate_2026_10_24/tools/merge_sources.py
node "C:/Users/shiqing peng/.codex/skills/academic-search/scripts/academic-records.mjs" validate --input 00_project_management/ai_selector_ai_candidate_2026_10_24/combined_records.json --output 00_project_management/ai_selector_ai_candidate_2026_10_24/validation.json
node "C:/Users/shiqing peng/.codex/skills/academic-search/scripts/academic-records.mjs" dedupe --input 00_project_management/ai_selector_ai_candidate_2026_10_24/combined_records.json --output 00_project_management/ai_selector_ai_candidate_2026_10_24/deduplicated.json
```

search_neighbors.py默认复用已有原始响应，包括失败记录，不会假装重新查询成功。merge_sources.py使用已保存核查时间，不会在未重新核查网页时刷新来源日期。要更新检索应另建带日期的批次，不删除本批证据。

以上都是文献处理命令，不是模型复现命令；因此本轮没有实验配置、种子政策、统计单位或新模拟结果可报告。
