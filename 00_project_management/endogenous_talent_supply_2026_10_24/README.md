# 从“候选人内生”到“评价如何塑造可识别人才供给”

日期：2026-10-24。性质：理论推进、近邻证据核验、现有模型只读审计；不是新实验结果，也不是已经确认的首创性声明。

## 结论先读

“评价改变候选人，所以放松被评价对象外生的假定”是成立的模型转换，但不足以单独构成文献贡献。已有研究已覆盖评价诱发投资、技能真实改进、认证与培训互补，以及人群与制度的多轮相互适应。

较值得推进的候选问题是：**当可见缺口混合能力不足与证明机会不足时，招聘反馈和验证机会的联合设计，如何改变后续可识别的人才供给？** 它必须产生超出一般投资激励、认证效应和可行性约束的可反驳预测，才可能成为理论增量。
