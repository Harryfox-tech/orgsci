---

摘要

AI招聘系统的作用可能不仅仅是筛选申请人：当它们返回基于证据的评估、解释技能差距并规定发展任务时，它们可以改变后续的技能投资和机会分配。本文使用一个包含四个连续制度的受控基于代理的劳动力市场实验来审视AI招聘作为社会技术反馈制度：凭证/文本筛选、基于证据的排名、带有解释的基于证据的排名，以及带有主动发展任务的基于证据的排名。在40个配对的随机社会中，基于证据的排名/信息集干预提高了被录用者的条件潜在匹配度，但降低了短期市场出清率和每个可用职位的总实现匹配度。解释性反馈将学习努力重新导向缺失的技能，而主动任务增加了实现技能收益和从弱证据到可验证证据的转化，但并未改善六轮安置。在一个2×2×2的结构设计中，证据渠道对R1-R0资源关联安置差距变化的直接配对效应为+0.133（95% CI 0.041至0.225；p=0.0096；10个配对种子），而证据与学习以及证据与凭证资源的交互作用则无法检测到。当证据置信度折扣规则被移除时，模拟的凭证敏感性下降消失或逆转，因此它被作为构造检验处理。这些结果识别了在特定假设下模型生成的风险机制，而非真实劳动力市场的经验效应大小。

关键词： AI招聘；算法反馈；基于技能的招聘；基于代理的建模；机会不平等；技术治理

---

摘要总结

本文通过基于代理的劳动力市场模拟实验，研究了AI招聘系统作为社会技术反馈制度的影响。研究发现，基于证据的AI招聘虽然提高了被录用者的潜在匹配质量，但同时增加了市场摩擦（降低安置率、延长搜索时间）。解释性反馈和主动任务能改变候选人的学习轨迹，但在六轮模拟期内未转化为明显的就业改善。此外，研究识别出一个模型生成的风险路径：当资源获取不平等仅通过证据生产渠道运作时，资源关联的安置差距会扩大。这些发现是机制性的，而非对真实劳动力市场的预测性估计。

1 引言

人工智能正日益嵌入招聘、就业能力平台和基于技能的招聘举措中。然而，主导的评价视角仍将招聘AI视为排名或预测设备：给定简历和职位描述，系统能多准确地识别匹配、面试或申请的候选人？这一视角忽略了一种更广泛的社会可能性。一旦招聘系统解释了缺失的技能、突出了证据差距或规定了发展性行动，它就可以影响候选人如何投资自己以及机会如何在劳动力市场中分配。

这个反馈问题连接了三个文献领域。劳动力市场信号理论解释了为什么雇主在生产力不完全可观察时依赖可见凭证[1]。人力资本理论预测个体会根据预期回报和成本分配学习努力[2]。人岗匹配和可解释推荐研究越来越多地使用更丰富的候选人-工作兼容性表征[3, 12-14]，但通常将候选人特征视为推荐系统的外生变量。动态招聘平台打破了这一假设：排名影响反馈，反馈影响投资，投资改变未来的能力和可观察证据。

图1 连接申请、排名、雇主决策、返回反馈、候选人投资、证据获取约束和下一轮状态的社会技术反馈循环。证据基础设施改变获取/成本，而非直接授予潜在能力。

我们使用AdapLink（一个基于证据的人才适应系统）为这一机制开发了一个计算框架。本文做出了两个旨在防止循环结论的设计选择。首先，潜在的任务相关能力与TAI/短名单排名规则可用的证据相分离；排名模型不能定义自己的成功标准。模拟雇主尽管如此仍会在短名单后收到一个不完美的绩效代理，在第3.5节中描述，因此潜在能力不被假设对最终招聘阶段完全不可见。其次，基于证据的排名、解释和主动发展按四个制度顺序引入，因此它们的效果不会被捆绑。

主要分析是一个受控的随机基于代理的模型（ABM），而非LLM原生模拟。这一选择使行为和制度假设明确化并允许精确复制。社会初始化是基准知情的：它匹配来自公开候选人-工作匹配数据集的已发布总体设计约束（4:1候选人-工作比率、24个角色、10个行业、73项技能、三个资历级别和平均技能数量）[26]，而不将行为参数拟合到记录级结果。四十个配对种子生成仅在招聘制度上不同的克隆社会。一个历史开放数据TAI代理实验在补充说明S1中记录以提供实施背景，但它不是本文确证证据链的一部分。

1.1 研究问题

RQ1. 基于证据的排名是否相对于凭证/文本筛选改善了潜在候选人-工作匹配度并减少了搜索摩擦？

RQ2. 模拟的凭证敏感性下降在多大程度上依赖于雇主使用的证据置信度折扣规则？

RQ3. 解释性反馈是否改变了候选人如何分配技能投资，超越了R1基于证据的排名/信息集干预？

RQ4. 主动学习路径任务是否创造了超出单独解释的额外实现技能和证据收益？

RQ5. 基于证据的招聘是缩小还是扩大了初始获取证据生成资源机会较多和较少的候选人之间的资源关联安置差距？

1.2 贡献

本文在四个方面做出贡献。首先，它将AI招聘重新框定为连接选择、学习、信号生产和后续分配的社会技术反馈制度。其次，它区分了潜在能力、可见技能声明和证据可信度，使得TAI/短名单排名不会用其优化的相同表征来评估，同时明确建模雇主不完美的短名单后绩效信号。第三，它在受控的多轮劳动力市场中估计了基于证据的排名/信息集干预、解释性反馈和主动任务效应，并配有中性对照和配对社会。第四，它隔离了一个模型生成的风险路径，其中获取证据生成资源的不平等可以扩大资源关联的安置差距，即使资源-学习渠道被关闭；这是实证研究的可证伪机制假设，而非测量的劳动力市场效应。

第1节总结（引言）

本节介绍了研究背景：AI招聘不仅是筛选工具，更是能影响候选人技能投资和机会分配的社会技术反馈制度。研究使用基于代理的建模（ABM）方法，设计了四个逐步递进的招聘制度（R0-R3），通过40个配对种子社会进行模拟实验。研究提出了五个研究问题，核心贡献在于将AI招聘重新框定为反馈制度，区分潜在能力与可见证据，并识别出资源不平等可能通过证据渠道单独扩大安置差距的风险机制。

2 AI招聘作为社会技术反馈制度

2.1 反馈制度与执行性适应

社会技术系统不能仅从人工制品本身来理解，因为结果源于计算规则、组织行为者和用户之间的相互作用[27]。因此，本文将招聘AI建模为反馈制度：信息规则对候选人排名；雇主根据该排名行动；平台返回反馈；候选人调整技能投资和证据生产；改变的候选人状态进入下一轮分配。这与静态的人岗匹配问题不同，因为系统帮助生产了未来输入的一部分，而它稍后将对该输入进行评估。

这一框架连接了三个已确立的观点。首先，算法系统通过记录、评级、推荐和奖励特定形式的行为来重组组织控制和评估[28, 29]。其次，公共度量和排名可以是反应性的：行为者因为被评估而改变行为，从而重新创造系统测量的社会环境[30]。第三，执行性预测形式化了更广泛的观点，即用于决策的预测可以改变结果生成分布本身[31]。在招聘中，解释和发展任务提供了一个特别直接的适应渠道，使候选人投资和证据形成成为平台设计的内生变量。

2.2 信号与基于证据的招聘

雇主无法在招聘前完全观察生产力，因此依赖可见信号，如教育、学校、专业、证书、工作经历和面试表现[1, 4]。职业技能要求包含超越广泛凭证的信息[5]，近期工作强调了技能、学位和算法凭证使用的分配后果[6, 8, 9]。基于证据的招聘改变了信息集：相同的声称技能可以根据是否由课程项目、实习成果、竞赛结果、作品集或其他可验证经验支持而携带不同权重。

重要的是，证据可信度与潜在能力并不相同。一个强有力的候选人可能缺乏生成作品集证据的机会，而一个资源丰富的候选人可能更能使相似的能力变得清晰可读。将证据视为可观察信号而非真实生产力度量，使模型能够检验信息收益和新形式的不平等。

2.3 解释作为信息干预

二元拒绝几乎不提供关于不同学习行动预期回报的信息。可解释匹配可以相反地将结果分解为已覆盖要求、缺失技能和弱证据技能[14, 16]。根据人力资本理论，这种信息可以改变对定向学习的感知回报[2]。因此，我们将解释制度与主动发展制度区分开来。R2改变信息但不机械地授予能力。R3额外提供一个可能被拒绝且其实现收益是随机的任务。

2.4 证据获取与资源关联的安置差距

基于技能的招聘不一定是分配中性的。获取实习、研究项目、竞赛、指导、设备和作品集构建机会的机会影响候选人将能力转化为可见证据的成本。我们使用证据获取优势来描述这种在上游生成可信可观察证据的能力差异。然而，主要的分配结果是一个不同的下游数量：资源关联的安置差距，定义为在同一种子社会内初始资源获取前四分位候选人的最终安置率减去相应后四分位的安置率。修订后的结构设计分别切换资源对证据生产、潜在学习和学校/凭证信号的影响，允许模拟检验安置差距是否仅通过证据渠道就能产生。这两个构念都是模型生成的机制，而非外部测量的劳动力市场弹性。

第2节总结（理论框架）

本节将AI招聘重新概念化为"社会技术反馈制度"，连接了算法控制理论、排名反应性和执行性预测三个文献。核心论点是：AI招聘系统不仅是筛选工具，更能通过反馈改变候选人的行为和未来状态。研究区分了潜在能力与证据可信度，指出基于证据的招聘可能引入新的不平等形式——资源关联的安置差距。预先设定了五个可检验的命题（H1、C1、H3、H4、RQ5），明确了各假设的支持/不支持标准。

3 方法论框架

3.1 测量架构

设 K = \{k_1,\ldots,k_n\} 为共同技能空间。候选人 i 具有潜在能力 a_i、可观察技能声明 s_i 和证据可信度 c_i。工作 j 具有需求向量 d_j。基于证据的可观察表征为：

\tilde{s}i = s_i \times c_i \quad (1)

TAI/短名单排名系统观察 s_i 和 c_i，但不观察 a_i。真实匹配度（GTF）从潜在能力和工作需求定义为评估基准。然而，在最终雇主选择阶段，模拟雇主会收到一个从GTF生成的噪声任务/面试绩效代理；因此潜在能力对TAI排名不可用，但不假设对雇主完全无信息。

{GTF}{ij} = 1 - \frac{\sum_k \max(d{jk} - a{ik}, 0)}{\sum_k d{jk} + \epsilon} \quad (2)

这一架构防止基于证据的TAI/短名单规则使用其优化的相同证据加权表征来评估。噪声绩效代理在所有制度中共享，因此不会创造制度特定的潜在基准获取。

图2 分离TAI/短名单排名观察的证据与潜在绩效基准的信息流。TAI不直接观察潜在能力；最终雇主选择收到一个共同的噪声任务/面试代理，而GTF保留用于外部匹配评估。

3.2 基于证据的TAI信号

AdapLink将技能表示为共现图，并通过五个可解释的TAI维度总结可观察兼容性：覆盖率、相关性、差距、支持度和潜力。在执行的ABM中，训练好的神经TAI不在每个社会内部重新估计。相反，一个冻结的TAI风格证据分数被用作制度信号：工作需求与证据加权技能声明之间的加权重叠，辅以证据支持度、观察技能重叠、相邻潜力、行业对齐和资历兼容性。潜在能力从不进入该分数。

3.4 基准知情的结构初始化

主要ABM不使用私人申请人记录。其基准知情的结构初始化遵循公开的MIT许可候选人-工作匹配合成数据集[26]，该数据集报告了10,000份简历、2,500个工作、4:1供需比、24个角色、10个行业、73项独特技能、平衡的初级/中级/高级级别、平均每份简历6.5项技能和每个工作5.0项技能。模拟生成满足这些已发布总体设计约束的新鲜微观状态。它不将行为参数拟合到记录级基准结果，因此不应被解释为该数据集的实证重建或校准。

每个配对种子包含120名候选人和30个工作，保持4:1比率。角色原型包含六项核心技能；工作围绕均值五项抽取四到七项所需技能。候选人活跃技能数量围绕均值6.5抽取。资历在三个级别间平衡。资源获取是一个连续的潜在禀赋。在基线模型中，它可以通过分别参数化的梯度影响证据可信度/更新和学习；学校/凭证信号也可以与资源获取相关。结构稳健性设计独立切换这三个渠道，因此证据-资源路径不是从资源必然改变潜在学习的模型中推断出来的。

3.5 雇主和候选人决策

候选人每轮最多提交三份申请，使用基于感知技能重叠、角色/行业亲和力、资历可行性、工资价值、目标工作偏好和可观察证据的随机效用。雇主短名单每份工作最多五名申请人。R0短名单分数加权关键词重叠、专业/行业对齐、学校信号和资历；R1-R3使用冻结的基于证据的信号。最终雇主选择组合噪声任务/面试绩效代理 z{ij}、短名单分数 r{ij}、学校信号和角色/专业匹配：

{score}{ij} = \frac{0.48z{ij} + 0.30r{ij} + w{cred} \cdot school_i + w{major} \cdot major{ij}}{0.78 + w{cred} + w{major}}

绩效代理为 z{ij} = clip(GTF{ij} + \mathcal{N}(0,0.10), 0, 1)，代表短名单后观察的不完美结构化面试、工作样本测试或工作相关技能评估。它在所有制度中由相同函数生成，且对TAI/短名单规则不可用。雇主凭证先验 p_j 从 Beta(2.3, 4.7) 抽取，重新缩放至请求的均值0.33，并裁剪至[0.03, 0.80]。证据置信度 q{ij} 在R0中等于 0.18 + 0.25 \times (关键词重叠)，在R1-R3中等于 clip[0.10 + 0.75 \times (证据支持度) + 0.15 \times (证据重叠), 0, 1]。学校和专业的权重为 w{cred} = \frac{p_j}{1 + \lambda_c q{ij}}，\lambda_c = 2.0，和 w{major} = \frac{0.12}{1 + \lambda_m q{ij}}，\lambda_m = 1.3。因为这种函数形式直接诱导凭证替代，凭证敏感性被作为构造检验处理；20种子对照从零到强折扣成比例变化两种折扣强度。

每份工作在六轮范围内有两个职位。给定轮次中每份工作最多录用一名候选人。被录用的候选人离开市场；未填补的容量持续存在。雇主和学生随机选择使用固定的种子特定随机流。模型记录申请、短名单、录用、学习和轮次状态事件。

3.6 学习、解释和证据形成

失业候选人在每轮后投资。在R0-R1下，学习是弱定向的。在R2下，候选人可以接受解释并将大部分努力导向最大的观察目标工作差距。在R3下，候选人可以额外接受主动发展任务。学习质量和接受率保持随机。资源依赖与干预内容分离：学习乘数以基线资源=0.5水平为中心，乘以独立可切换的资源-学习梯度 \rho_L。证据可信度有其自己独立可切换的资源梯度。质量达到或超过0.55的已完成R3任务按设计创建可验证成果；因此证据转化是一阶干预结果，而下游安置和匹配仍是涌现的市场结果。

指导和评估有意使用不同信息。R2/R3针对从证据可信度加权的可观察声明计算的最大差距，而定向投资对齐是针对平台无法观察的最大潜在能力差距评分的。因此对齐不是由干预标签机械定义的；它衡量可观察推荐是否与隐藏的任务相关赤字重合。

a{i,t+1} = clip[a{i,t} + learning\_rate_r \times quality{i,t} \times m_r(resource_i; \rho_L) + noise{i,t}] \quad (3)

3.7 推断、完整性检验和敏感性分析

处理在克隆社会层面分配，因此个体申请不是独立处理单元。主要实验使用40个独立配对种子（1000-1039），每个在R0-R3下运行六轮。因此主要推断使用配对运行级差异。对于运行级结果Y，顺序对比为：

\Delta_1 = mean_s(Y{R1,s} - Y{R0,s}), \quad \Delta_2 = mean_s(Y{R2,s} - Y{R1,s}), \quad \Delta_3 = mean_s(Y{R3,s} - Y{R2,s}) \quad (4)

对于配对对比a-b，令 d_s = Y{a,s} - Y{b,s}。我们报告 \Delta = mean_s(d_s)，独立种子级差异上的95% t区间，MCSE = \frac{sd(d_s)}{\sqrt{n}}，和配对Cohen d_z = \frac{\Delta}{sd(d_s)}。事件日志用于机制总结，但不膨胀独立处理分配的数量。对于2×2×2资源渠道设计，种子级证据主效应是L和C上 d_s(E=1,L,C) - d_s(E=0,L,C) 的平均值；E \times L 和 E \times C 是相应的种子内双重差分，在剩余因子上平均。运行前完整性检验验证每个制度恰好40个种子、种子/制度内无候选人被录用两次、工作容量从未超过两次录用、所有轮次在1-6内，以及所有关键结果范围。

确证多重性家族包含在报告种子批次运行前固定在模拟协议中的八个对比：H1匹配度、安置和搜索时间；H3投资对齐和总差距减少；以及H4差距减少、证据转化和安置。这些对比是运行前预先指定的，但未外部预注册。Holm校正应用于八个检验。凭证敏感性构造检验和探索性资源关联安置差距RQ5单独报告，而非纳入家族。

稳健性分析将种子不确定性与结构不确定性分离。除了补充表S3中报告的六个单因素敏感性设置外，2×2×2因子结构设计使用每个单元10个配对种子，独立切换(i)资源到证据梯度E，(ii)资源到学习梯度L，和(iii)资源与学校/凭证信号的相关性C。完整的八单元结果在补充表S4中报告，E、E×L和E×C的直接配对因子估计量在补充表S5中报告。一个聚焦的凭证权重诊断使用20个配对种子在无、一半、基线和强证据置信度折扣函数下运行。最终录用制度检验使用20个配对种子变化短名单后代里噪声（0.05/0.20对比0.10基线）和录用阈值（0.46/0.52对比0.49基线）；这些运行检验主要质量-摩擦权衡是否绑定于一种最终雇主配置。RQ5是探索性的，不包含在确证多重性家族中。

为分离一阶操纵与下游效应，R2-随机用随机工作相关指导替代最大差距指导，R3-随机用随机工作相关任务替代定向任务，同时保持干预强度。这些诊断使用固定种子子集1000-1019（20个配对种子）；补充表S7-S8报告中性对照和任务平衡估计量，补充表S9报告5/10/15/20种子收敛和蒙特卡洛标准误差。对于R3与R3-随机，在种子层面检验接受率、完成率、接受任务质量和接受任务资源组成。报告分配级实现匹配度每个可用职位，因此录用条件匹配度不被脱离市场出清背景解释。

操作定义固定在运行级，除非另有说明。资源关联的安置差距是初始资源Q4组的最终安置率减去Q1组的最终安置率，四分位切点在每个种子基社会内处理前计算，然后在其克隆制度间保持共同。凭证敏感性是运行末的简历内审计：对于每个候选人-目标对，学校信号被反事实反转而其他所有成分保持固定，确定性录用倾向的绝对变化在候选人上平均。定向投资对齐是学习事件中分配给候选人当前目标工作潜在最大差距技能的学习努力份额的均值事件级。每个可用职位的总实现匹配度是所有录用上GTF的总和除以运行中60个可用职位（30个工作×2个职位）。总潜在差距减少比较每个候选人初始和最终差距到相同初始目标工作；弱到可验证证据转化是初始弱（<0.40）所需技能达到可信度≥0.55的轮次末份额。附录A.6总结这些估计量和平均级别。

第3节总结（方法论）

本节详细描述了基于代理的模型（ABM）架构。核心设计包括：(1) 分离潜在能力与可见证据，防止排名规则自我评估；(2) 四个顺序制度（R0-R3）逐步引入干预；(3) 使用40个配对种子社会进行受控实验，确保仅招聘制度不同。模型初始化基于公开合成数据集的总体约束。关键机制包括候选人的随机申请行为、雇主的短名单和最终选择规则（含噪声绩效代理）、以及不同制度下的学习和证据更新规则。研究采用配对t检验和Holm多重校正，并设计了2×2×2因子结构分解资源渠道效应，同时通过中性对照（随机指导/随机任务）分离一阶操纵与下游效应。

第4节总结（模拟结果）

本节报告了核心实验结果：

1. 质量-摩擦权衡（H1）：R1（基于证据的排名）提高了录用者的条件匹配度（+0.029），但降低了安置率（-0.042）、增加了搜索时间，系统级实现匹配度反而下降。这是一个"质量-摩擦权衡"，而非单纯的效率提升。

2. 凭证敏感性与资源差距（C1/RQ5）：凭证敏感性下降依赖于特定的折扣规则，属于构造检验。关键发现是：即使关闭资源对学习的影响，仅保留资源对证据生产的影响，R1-R0的资源关联安置差距仍扩大+0.133（p=0.0096）。这意味着基于证据的招聘可能通过证据获取不平等单独扩大机会差距。

3. 解释效应（H3）：R2（解释）大幅提高了定向投资对齐（+0.269）和潜在差距减少，但未转化为短期安置改善。

4. 主动任务效应（H4）：R3（主动任务）进一步增加了技能差距减少和证据转化（+0.077），但同样未改善六轮安置率。

所有主要结果通过Holm校正、中性对照、任务平衡检验和多种稳健性检验得到验证。

5 讨论：AI招聘的社会影响

5.1 AI招聘可以改善匹配度同时增加市场摩擦

最强的市场级结果不是一个简单的"AI更好"的发现。在基线最终录用制度下，R1基于证据的排名/信息集干预改善了被录用者的条件匹配度，但也使市场在短期更难出清。对短名单后代理噪声和录用阈值的局部敏感性保留了这一权衡的方向，尽管其幅度仍依赖于制度。因此，基于证据的招聘可以在测试的设置中提高条件匹配质量，同时增加搜索摩擦。这在社会上很重要，因为平台、大学和雇主可能否则会将排名质量的改善过度解释为劳动力市场本身功能的改善。

这限制了常见的平台叙事，即将更好的排名等同于更好的劳动力市场效率。对研究者而言，它建议评估应同时报告条件匹配质量和系统级出清结果。对产品设计而言，它建议更严格的证据信号可能需要补充政策，以扩大产生证据的机会或在市场稀薄时放松阈值。

5.2 人才塑造首先出现在学习轨迹中，而非安置率中

R2和R3结果将行为塑造与即时就业分离。解释戏剧性地改变了努力分配位置并增加了潜在差距减少，而主动任务增加了进一步的技能/证据形成。然而，两个组成部分均未产生可检测的六轮安置改善。这不是对塑造假设的否定。它表明在特定范围内，微观级投资与宏观级招聘结果之间存在滞后。

这一发现也说明了为什么静态离线推荐测试无法回答核心问题。一次性基准观察今天谁被排名。ABM观察反馈是否改变了明天将被排名的状态。因此，该模型以动态机制补充了人岗匹配工作[12, 13]，而非声称一个普遍更优越的预测器。

5.3 资源关联的安置不平等是模型生成的风险路径

修订后的诊断分离了两个不应混淆的声明。凭证敏感性的下降对雇主折扣函数敏感，因此是构造检验，而非一般行为发现。上游机制是获取证据的不平等；下游测量结果是资源关联的安置差距。在主要基线比较中，差距扩大集中在Q1安置的下降上，而因子证据渠道分解将一个不太精确的Q1损失与一个更精确估计的Q4收益结合。因此，相同的总差距可以反映筛选排斥、累积优势或两者。在仅证据结构条件下，即使资源对潜在学习和学校/凭证信号的影响被关闭，R1-R0安置差距仍扩大，直接证据渠道因子效应为+0.133（95% CI 0.041至0.225；t基p=0.0096；精确符号翻转p=0.0156）。在此指定的计算社会内，奖励可见证据因此可以通过产生该证据的能力不平等生成机会分配路径。

该结果仍应被解释为模型生成的风险假设。结构单元使用合成代理，每个因子单元仅10个配对种子，以及未从真实申请人轨迹估计的参数值。不显著的E×L和E×C交互未确立零调节；它们仅表明此设计在当前精度下未检测到额外交互效应。模拟识别了一个可能存在的机制，而非其经验流行度或幅度。真实世界检验需要测量获取项目、实习、指导和作品集基础设施的机会，然后估计基于证据的选择是否在控制潜在技能增长和凭证信号后改变了资源关联的安置差距。

5.4 对教育、雇主和技术治理的影响

对平台设计而言，模拟意味着评估应超越排名准确性扩展到反馈效应：返回什么信息、奖励什么行为、以及它是否改变未来申请人分布。这遵循算法度量可以重组行为和制度实践的社会技术性和执行性视角[27-31]。对大学而言，模型促使关注证据基础设施——项目获取、真实评估、作品集、研究机会和低成本行业任务——因为能力必须在基于证据的系统能够奖励它之前变得清晰可读。对雇主而言，基于证据的筛选可以改善条件匹配度，但应监测吞吐量和群体特定的安置变化。Q1/Q4分解对治理很重要：由Q1损失驱动的差距指向排斥保障和替代证据路径，而由Q4收益驱动的差距更直接地指向平等化获取证据生成机会。对公共治理而言，模拟生成的是风险假设而非政策处方：公平审计可能需要检验生成被奖励证据所需的成本和机会，而非仅学校标签是否被明确包含。

5.5 局限性

发现是计算性的、有条件的，并故意比真实世界因果声明更窄。首先，主要总体是从公开合成基准的已发布总体属性生成的；它不是实际申请人的样本。资源-证据关系、雇主决策规则、学习率、任务接受率和容量是需要经验校准的结构假设。其次，技术TAI试点使用代理标签，无法确立招聘效度。第三，R3中的证据转化部分是一操纵检验，因为成功任务被定义为生成可验证成果。第四，当前ABM使用随机基于规则的代理而非LLM原生代理。这提高了报告因果对比的透明度，但省略了更丰富的语言介导解释和偏好异质性；未来的AgentSociety 2实现[22]应被视为稳健性扩展，而非悄然替代当前结果。

外部验证应将模拟的申请集中度、解释接受率、目标转换、任务完成和纵向技能/证据变化与真实平台日志、人类主体实验或HR注释进行比较。最小前瞻性检验将随机化符合条件的求职者接受粗略反馈、定向差距解释或定向发展任务；测量项目、实习、指导和作品集基础设施的基线获取；并跟踪证据创造、申请、面试和安置在预先指定的范围内。一个补充的平台推广设计可以估计基于证据的排名是否在控制基线技能和凭证信号的同时，跨队列不同地改变Q1/Q4安置。证据获取优势与下游资源关联的安置差距之间的区分对验证获取证据生成机会的真实差异特别重要。在获得此类验证之前，数字效应大小应被解释为指定计算社会的属性，而非实际申请人和就业结果的预测。

第5节总结（讨论）

本节讨论了研究发现的社会影响：

1. 质量-摩擦权衡：AI招聘改善排名质量不等于改善市场效率，需要同时关注条件匹配度和系统级出清率。

2. 人才塑造的滞后效应：解释和主动任务改变学习行为，但短期（六轮）内未转化为安置改善，说明微观投资与宏观结果存在时间滞后。

3. 资源不平等风险：基于证据的招聘可能通过"证据获取优势"单独扩大安置差距（+0.133），这是一个需要实证检验的模型生成风险假设，而非已确立的经验事实。

4. 实践启示：平台应评估反馈效应；大学应建设证据基础设施；雇主应监测群体安置差异；治理应关注证据生成成本而非仅标签偏见。

5. 局限性：研究使用合成代理和结构假设，需要外部验证才能推广到真实劳动力市场。

---

6 结论

AI招聘可以影响谁被选择以及候选人投资的信息环境。在此基准知情的计算劳动力市场中，R1基于证据的排名/信息集干预提高了录用者的条件潜在匹配度，但降低了短期安置率、增加了搜索摩擦，并减少了每个可用职位的总实现匹配度。解释和主动任务改变学习轨迹和证据形成，但未产生可检测的六轮安置增益。中性对照显示定向指导超越通用额外学习而重要，任务平衡检验排除了接受率、完成率、质量或接受用户资源的简单差异。结构渠道分解和直接因子对比进一步显示，模型生成的资源关联安置差距可以仅通过证据生产产生，而模拟的凭证敏感性下降强烈依赖于明确指定的折扣函数。因此，产生的贡献是机制性的而非预测性的：AI招聘可以被研究为能够重塑未来信号和机会结构的反馈技术，而这些效应的经验大小和流行度仍是真实世界验证的问题。

---

第6节总结（结论）

本节总结全文核心发现：AI招聘作为反馈技术，在提高条件匹配质量的同时增加了市场摩擦。解释和主动任务能改变学习行为但存在效果滞后。关键风险在于，基于证据的招聘可能通过证据获取不平等扩大机会差距，且这一效应独立于资源对学习或凭证的影响。研究贡献是机制性的——识别了可能存在的因果路径，而非提供经验预测。数字结果应视为特定计算社会的属性，需要真实世界数据验证。

A.1 概述和过程时间表

每个社会包含120名候选人、30个工作、73项技能、24个角色原型和10个行业。在六轮中的每一轮内：(1)失业候选人最多提交三份申请；(2)雇主为申请人评分并短名单最多五人；(3)每个开放工作可以在该轮录用最多一名候选人，受两轮范围内两次录用的容量限制；(4)被录用的候选人离开市场；(5)失业候选人接受制度特定反馈并学习；(6)记录差距、证据状态和开放容量。处理是分配给克隆社会的招聘制度；种子是独立推断单元。

A.2 初始化分布

资源获取为 Beta(2.2, 2.2)，准备度为 Beta(4, 2)。候选人活跃技能数量为裁剪至4-11的 Poisson(6.5)。初始活跃技能能力为 \mathcal{N}(0.65 + 0.10 \times 资历, 0.13) 裁剪至[0.15, 1]。初始证据可信度等于 0.455 + \rho_E(资源 - 0.5) + 0.10 \times 资历 + \mathcal{N}(0, 0.12)，裁剪至[0.05, 1]。学校信号等于 0.275 + \rho_C(资源 - 0.5) + 0.075 \times 资历 + \mathcal{N}(0, 0.18)，裁剪至[0, 1]。观察声明对活跃技能等于能力 + \mathcal{N}(0, 0.10)，有0.45概率的一个额外纯文本声明。

A.3 申请、短名单和雇主决策函数

候选人感知效用为0.44关键词重叠 + 0.17角色匹配 + 0.09行业匹配 + 0.08资历可行性 + 0.10工资 + 0.14目标工作指示器 + 0.12证据重叠，加Normal(0, 0.035)噪声；使用softmax温度0.13的加权选择无放回。R0短名单分数为0.44关键词重叠 + 0.24角色匹配 + 0.10行业匹配 + 0.15学校信号 + 0.07资历。R1-R3短名单分数为0.67证据重叠 + 0.13证据支持度 + 0.08关键词重叠 + 0.06相邻潜力 + 0.04行业 + 0.02资历。令 z{ij} 为短名单后任务/面试代理，r{ij} 为短名单分数。最终雇主分数为 [0.48 z{ij} + 0.30 r{ij} + w_cred school_i + w_major major{ij}] / [0.78 + w_cred + w_major]，其中 z{ij} = clip(GTF{ij} + \mathcal{N}(0, 0.10), 0, 1)。雇主凭证先验 p_j 从 Beta(2.3, 4.7) 抽取，乘法重新缩放至均值0.33，并裁剪至[0.03, 0.80]。在R0中，q{ij} = 0.18 + 0.25 \times (关键词重叠)；在R1-R3中，q{ij} = clip[0.10 + 0.75 \times (证据支持度) + 0.15 \times (证据重叠), 0, 1]。然后 w{cred} = \frac{p_j}{1 + 2.0q{ij}} 和 w{major} = \frac{0.12}{1 + 1.3q{ij}}。任务/面试代理代表短名单后仅观察的不完美结构化面试、工作样本或技能测试信号；它对TAI不可用，在所有制度中相同生成。录用概率为 \Pr(录用) = logistic(\frac{分数 - 0.49}{0.06})。代理噪声、权重和阈值是结构假设而非经验校准的面试效度估计。

A.4 学习和证据更新

对于通用学习，m_g(r) = 0.775 + 0.45\rho_L(r - 0.5)；对于解释指导学习，m_e(r) = 0.750 + 0.50\rho_L(r - 0.5)；对于主动任务，m_t(r) = 0.960 + 0.08\rho_L(r - 0.5)。设置 \rho_L=0 移除资源依赖同时保留资源=0.5处的修正。通用、解释和主动任务学习率分别为0.035、0.072和0.120。自学证据使用修正0.675 + 0.65 \rho_U(r-0.5)和规模0.025；主动任务使用规模0.165。R2解释接受率为 clip[0.67(0.55 + 0.45准备度), 0, 0.95]。R3任务接受率为 clip[0.58(0.50 + 0.50准备度), 0, 0.95]。通用和解释质量是准备度缩放的Beta抽取；主动任务质量为 Beta(3.5, 2.1) \times 准备度 + \mathcal{N}(0, 0.05)，裁剪至[0, 1]。质量≥0.55的已完成主动任务将可信度提高到至少预先指定的可验证阈值。

A.5 随机性、对照和可重复性

每个种子创建一个在制度间克隆的基社会。制度特定随机流使用确定性偏移，而所有结构控制运行在每个比较内保留相同的种子范围。adaplink_abm_experiment_v2.py中的基线参数化精确复制存档的40种子主要结果。结构控制仅改变声明的梯度或凭证折扣参数。复制档案提供机器可读CSV输出、元数据、完整性检验和版本固定的依赖。
