- Store a shareable BibTeX/RIS export in `references/`.
- Store concise reading notes in `notes/`, ideally one note per source with a stable citation key.
- For every central claim, record both the supporting source and the intended manuscript section.
- Check journal and working-paper references before submission; do not rely on unverified citation metadata from generative tools.
