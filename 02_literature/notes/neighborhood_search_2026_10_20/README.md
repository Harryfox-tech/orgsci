# 发展建议、技能供给与人才配置：近邻排重

检索及核验日期：2026-10-20。承接Clark等（2018）全文阅读后的候选问题；优先Organization Science，同时检索Management Science、人力资本／匹配理论及计算机领域的直接机制近邻。

## 先看结论

**需要修正上一轮判断：建议改变技能供给、供给再进入后续预测与推荐，已经有相当直接的先例。** 目前不能把这条循环本身当作理论缺口，也不能据本轮检索宣布没有可投OrgSci的空间。更准确的状态是：宽泛贡献有明确重叠，具体组织机制尚待比较和证伪。

最重要的新增近邻是Kokkodis与Ipeirotis（2021），不只是Clark。该文已处理市场需求导向的技能学习、部分采纳、供给更新和未来回报预测，并讨论推荐集中导致技能供给饱和的问题。其主文§6.2说的是**没有显式建模完整均衡效应**，不是“完全没有供给反馈”。[作者公开正式稿](https://ipeirotis.org/wp-content/uploads/2020/06/mnsc.2020.3727.pdf)，§4.5、§5.1、§6.2；[期刊页](https://doi.org/10.1287/mnsc.2020.3727)。
