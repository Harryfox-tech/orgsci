更新：2026-09-28。用途：给研究者本人阅读、判断选题；不是可直接粘贴进投稿稿件的文献综述。

## 先说判断

我们的方向可以继续：研究招聘评价怎样改变未来被评价的人。但“招聘具有反馈”“候选人会适应”“证据与能力不同”本身都不足以作为新贡献。接下来应选一个可以和最近邻论文正面区分的组织理论张力，而不是把已有 ABM 再加几个模块。

这次保留原有材料，另建读者版。七篇采用相同骨架：真正的问题 → 理论转移 → 机制链 → 证据强度 → 可学方法 → 迁移方案 → 重叠风险 → 带着什么问题读原文。

## 这批阅读带来的共同修正

1. 不再把“没有一篇同时包含所有模块”称为理论空白。
2. 不预设证据越多就越不可信；分别观察数量、内容、预测效度和组织使用方式。
3. 不把没有录用解释成能力低：还可能是岗位、竞争、申请时机和名额问题。
4. 不把资源、性别、经验和网络位置当作同一个群体标签。
5. 不用人为写入的学习率优势证明发展制度优越，也不用预设信任衰减证明证据贬值。
6. 把反对我们选题的文献放进来：新增核验发现，招聘拒绝信息如何改变再申请已被直接研究，见选题文件。
