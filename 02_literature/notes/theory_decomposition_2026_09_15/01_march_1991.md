1. **Phenomenon.** Organizations simultaneously learn from present knowledge and search for new possibilities; gains and costs arrive at different times and levels [verified: abstract].
2. **Existing theory / assumption.** A static allocation view treats exploration and exploitation as choices from a fixed stock [analysis]. March's two models make the learning stock itself change; the exact prior-theory characterization requires introduction text.
3. **Why it matters.** A fast improvement can remove future variation, so one-period performance cannot identify the long-run value of a learning rule [analysis from abstract].
4. **Smallest mechanism.** Mutual learning between members and an organizational code, plus a separate model of competition for primacy [paper-verified: pp. 74–75, 81–85]. See the model inventory below.
5. **Design / result.** The first model compares learning rates, heterogeneity, turnover and environmental turbulence; the second compares mean/variance of performance under competition for primacy [paper-verified: pp. 75–85].
6. **Contribution / limit.** Learning practices change the future knowledge population; the abstract's model implication is not an empirical labor-market claim [analysis].
7. **Relation: adopt dynamic-stock logic.** Our feedback may change candidates' skills and evidence before the next employer evaluation. **Hypothesis:** fast, standardized responses may improve early alignment but narrow later skill diversity; this is untested in our ABM. ## What the paper actually relaxes

The introduction reviews rational search, aspiration-based search, organizational learning and evolutionary variation/selection rather than dismissing them as one static theory (pp. 72–73). March's decisive observation is that exploitation yields nearer, clearer and more certain feedback than exploration. Adaptive allocation therefore can learn to favor exploitation before distant exploratory returns appear (p. 73). The argument is not simply “balance two activities”: the *process that updates beliefs about their value* is biased by different feedback timing. The next two models show why that tendency may undermine future knowledge or change meaning in relative competition.

## Model 1: minimum executable anatomy

| Element | Verified representation/rule | Why it is necessary |
| --- | --- | --- |
| External reality | `m` independent dimensions, each `+1` or `-1` with equal probability (p. 74) | Allows knowledge to be assessed against fixed truth |
| Individuals and code | `n` individual vectors and one organizational-code vector; beliefs on each dimension are `-1, 0, +1`; the code starts at zero (pp. 74–75) | Gives two stocks that can learn from one another |
| Individual update `p1` | When code belief differs, an individual adopts code belief with probability `p1`; a zero in the code has no effect (p. 74) | Socialization reduces person–code variation |
| Code update `p2` | Code draws the majority view of members whose total knowledge exceeds the code's; probability depends on agreement and `p2` (pp. 74–75, note 1) | Heterogeneous superior members are the source of code improvement |
| Measurement | Proportion of reality correctly represented in code; average proportion correct in individual beliefs (p. 75) | Separates immediate individual gains from collective knowledge |

Crucially, individual `i` does not learn directly from `j`. Reality is also not directly revealed to either actor: superior individuals can still pass false beliefs to the code, and the code can pass false beliefs back (p. 75). Kane and Alavi later change the information architecture precisely at this indirect-transmission assumption. The formal loop is `individual beliefs → superior-member filter → code → socialization → individual beliefs`; convergence removes the very deviations the code requires for further improvement.

Baseline closed system: `m=30`, `n=50`, 80 stochastic replications with fixed membership and stable reality; the paper states qualitative patterns are insensitive to `m` and `n`, while quantitative levels depend on them (p. 75). The text calls these repeated simulations, but does not report the modern paired-seed or software-version policy we use in our archive. Do not retroactively call March's design “paired seeds.”

## Evidence chain: why faster learning can be worse

**Figure 1 (pp. 75–76)** crosses `p1` and `p2`. Lower socialization (`p1`) yields more equilibrium code knowledge, especially when code learning (`p2`) is fast. Fast socialization gives individuals a first-order benefit because the code is usually more knowledgeable than the average individual; its second-order cost is that the code loses deviant members from whom to learn. The strongest equilibrium result is therefore *slow individual learning together with fast code learning*, an interaction rather than a simple prescription to slow all learning.

**Figures 2–3 (pp. 76–78)** contrast homogeneous `p1` with a mix of `0.1` and `0.9` at the same average socialization rate. The heterogeneous population has higher equilibrium knowledge. Slow learners contribute disproportionately to code improvement, while fast learners reap more of the knowledge benefit before equilibrium. March explicitly notes the incentive problem: if individuals choose their own speed, there is no obvious reason to volunteer to learn slowly for collective benefit (p. 77). This is a genuine micro–macro conflict, not merely a diversity slogan.

**Turnover (pp. 77–79, Figure 4)** introduces departure/replacement probability `p3`. Newcomers are less knowledgeable on average, so turnover immediately lowers population knowledge. Yet moderate turnover can raise code knowledge by bringing nonredundant beliefs into a strongly socialized organization. This result depends on recruitment being *unaffected by the code*: selecting recruits close to the code would erode turnover's exploratory value (p. 81). That caveat is especially relevant to our recruitment loop because employer screening can select from and reshape the entrant pool.

**Turbulence (pp. 79–81, Figure 5)** flips each dimension of reality with probability `p4`. Without variation, person and code beliefs become identical and cannot move even while reality changes; after initial improvement, learning is eventually degenerate while measured accuracy deteriorates. With `p4=.02`, Figure 5 contrasts `p3=0` and `.1`; turnover keeps an avenue for adjustment. Thus the beneficial role of turnover is conditional on both socialization and environmental change. We must not translate `p4` into a labor-demand-change parameter without stating a new mechanism.

## Model 2: why the performance criterion changes the answer

March then analyzes a reference organization competing for primacy against `N` others. Each has a normal performance distribution with mean and variance; the relevant outcome is the probability that the reference organization beats *all* others, not its average performance alone (pp. 81–83, Figures 6–7). With one competitor, higher mean helps independent of variance; as the competitor count grows, variance and the right tail can become valuable even when they lower average performance (pp. 82–85). The two models do not share a single agent-level learning implementation. The second is a theoretical counterpoint: whether exploration is useful depends on how rewards are allocated across organizations.

## What we should actually borrow

`Paper-verified`: a few explicit micro-rules generate an interaction, a short/long reversal, a micro/collective incentive split and environment-dependent value of variation. `Our analysis`: our model's evaluated candidates are outside the organization, can invest in *capability* and in *observable evidence*, and face a selection institution that may alter recruitment of the next pool. March's p. 81 recruitment caveat is a sharper bridge than a generic exploration citation. A minimal handoff test is to compare targeted feedback with candidate adaptation disabled, then record skill and evidence diversity at each round before judging long-run fit. A falsifier would be durable fit gains without the proposed diversity/stock channel. Neither a diversity collapse nor a reversal is currently a verified result of our locked archive.
