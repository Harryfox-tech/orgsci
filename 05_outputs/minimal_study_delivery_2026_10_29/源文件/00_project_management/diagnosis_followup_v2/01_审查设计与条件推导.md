# 方案一推进：先审查关键假定，不扩大ABM

承接用户“继续推进”及Acemoglu—Pischke全文对照。这是独立v2审查，保留v1及旧复制包。以下设计在本轮v2数值运行前写出；不是预注册或现实校准。

## 1. 两个要审查的问题

1. v1只计算二元岗位达标，已达标者培训不再增加这一指标。若他们仍能提升潜在生产能力，私人收益与能力形成的分离还在吗？
2. v1的候选人只靠公共先验与诊断判断自身情况。若候选人已有自己的信息，AI还能在多大条件范围内改变行动？

不在这轮加入多岗位竞争、机构重训或新生代；也不把“认证内容不同”未经建模就当作已检验的贡献。

## 2. 第一项扩展：允许达标后继续成长

保留v1的K∈{0,1}及招聘测评。潜在产出基准分别为y₀=1、y₁=2，差D=1。未达标者经L以α概率达标，成功带来产出增量D；已达标者经L仍可增加b≥0的潜在产出，V的对应增量基准为0。

这是非二元产出指标，但主体类型与可能结果仍是有限的；不能称完整连续技能分布模型。招聘测评仍只认岗位是否达标，未根据超额生产力调整工资或排序。

在后验缺技能概率p下：

```text
E[ΔY_L|p] = p αD + (1−p)b
E[ΔY_V|p] = 0                  基准纯验证
U_a(p) = w P(hire|a,p) + μ E[ΔY_a|p] − c_a
```

μ表示候选人对新增潜在产出的私人价值，允许其重视当次招聘之外的收益；不是内生工资或完整终身回报估计。μ=0不是唯一情形，审查0、0.25、0.5、1。

L相对V的价值差为：

```text
U_L−U_V = μb−(c_L−c_V) + p[αw(s−f)+μ(αD−b)]
```

系数可能为负或阈值落在[0,1]之外，因此不强迫存在“缺技能越多越选L”的内部阈值。参加与否仍须和N比较。

当没有私人信息、p₀=1/2，且实际策略仍为“无V时人人L，有V时S→L、E→V”，有V减无V的潜在产出增量差为：

```text
ΔE[新增潜在产出] = −0.5[α(1−q)D+qb]
```

第一项是部分缺技能者少接受一次培训；第二项是部分已达标者少获得继续成长。新增达标比例仍只对应第一项。这个解析式有策略条件，μ改变选择后不能套用。

如果结果保留，也只说明分离不依赖b=0；它不证明固定工资、机构不响应等其他假定无关，更不证明社会福利下降。

## 3. 第二项扩展：候选人有私人自我信息

候选人另观察私人信号h∈{S,E}，准确率r∈[0.5,1]。h与AI诊断z在给定初始K下条件独立；二者都只给候选人，雇主不看。候选人结合h和z更新，选择函数不读取K。

```text
后验赔率 = 先验赔率 × LR(h;r) × LR(z;q)
LR(S;t)=t/(1−t)，LR(E;t)=(1−t)/t
```

实际代码用联合概率而非无穷赔率处理r=1、q=1，零概率矛盾分支跳过。同r、同产出/回报条件下比较q=0.5与更高q，不能将私人自知的效果算到AI头上。

在L/V存在内部阈值β且N不约束时，令候选人仅用h后的赔率为O_h，阈值赔率B=β/(1−β)。新诊断可能使行动跨过阈值，仅当：

```text
B / LR(S;q) < O_h < B × LR(S;q)
```

等价为对数赔率距离落在诊断能够跨越的范围内。边界平局另按固定规则处理。该结论属于基本决策逻辑，不称新理论定理。

r=1时，给定自身真实状态，任何条件独立的额外诊断均不能再改变贝叶斯信念或最优行动。新增诊断的行为效应应消失，但验证机会本身仍可能有价值。r较高时，也可能存在未到1、但当前AI诊断不足以改变行动的区域。

## 4. 固定比较与否决标准

固定v1的初始分布、成本、学习成功率与最终测试规则，扫描：q∈{0.5,0.6,0.8,0.95,1}；r∈{0.5,0.7,0.9,1}；b∈{0,0.3,0.6,1.2}；μ∈{0,0.25,0.5,1}。320个参数组合，分别计算四种验证可及安排及两组/总体。

这些是透明的审查值，不估计实际人群分布。相同总名额仍不等于完整财政预算相同。数值精确枚举概率分支，无随机种子、p值或置信区间。

否决/修正条件：

- 若b>0但结果只能通过保持μ=0出现，就应把候选人不能获得/不重视增长回报写成必要边界，而非一般规律。
- 若较准自我信息使AI不再改变行动，后续研究必须先测自我认识，不能只操纵算法准确率。
- 若只是更多选项或信息的最优性事实，不能当作独立贡献。
- 一般框架可以容纳某模型，不等于已证明同一具体机制；相反，特定模型未写某变量也不等于有理论空白。
- 如近邻已给出同样机制和条件判断，收窄或转题，不通过加参数维持“原创”。
