# 方案一：机制验证草案与继续门槛

这是可供团队和导师审阅的设计，不是已经完成的行为实验、预注册或招募授权。目标是区分现实机制，避免只为最小模型寻找支持。

## 1. 先确认研究对象确实存在

需要从AdaptLink实际流程、组织测评/培训规则或具体案例中核对：

1. 是否存在独立任务已经显示能胜任，但组织目前缺少可接受证明的人；不能仅由算法说“证据少”就认定本人有能力。
2. 是否存在不必先修培训、而能独立证明既有技能的测评入口；组织是否真的接受它。
3. 培训自带结业测评与独立验证是否有不同获取条件；v1这一设定不能靠想象填充。
4. 候选人原先对自身技能了解多少；新的诊断是否提供了其尚未掌握的信息。
5. 改变的是建议文字、费用、名额还是申请资格；避免把消息内容与可行行动同时变化却归因于“诊断准确”。

如果这些对象或路径不存在，暂不扩大ABM。用户此前提供的论文解释理论机制，不等于这些现实制度事实已经到位。

## 2. 最小四组比较

以同一模拟岗位、相同任务、培训路径、最终评价标准与奖励为基础：

| | 无独立验证入口 | 有独立验证入口 |
|---|---|---|
| 无个性化诊断 | C00：依据既有信息选择学习/不行动 | C01：依据既有信息选择学习/验证/不行动 |
| 有个性化诊断 | C10：收到诊断，但没有V | C11：收到同一类诊断，并可选择V |

V入口是计划操纵的行动资格，不要求四组菜单相同；菜单之外的成本、任务与最终标准应控制。未实际等额核算时，不称财政预算配平。

第一步只检验信息与可及性。若后续要研究“AI诊断决定谁有资格验证”，必须另行比较建议与制度分流，不能把强制分配伪装成自愿采纳。

## 3. 必须有独立测量

- **处理前**：实际任务表现、对达标概率的判断、相关经验与已经拥有的证明；不将信心分数直接当信息准确率r。
- **处理后、行动前**：对自身达标的后验判断，以及对学习/验证回报和可行性的认识。
- **行动过程**：选择、实际时间/成本、完成与退出；允许不采纳建议。
- **最终结果**：新任务的独立表现与迁移成绩、岗位达标、获得可信证明、评估者的判断；分开记连续表现和二元达标。
- **差异检验**：谁减少重复培训，谁减少必要学习，谁只补了证明。不能只看总体培训频率。

同一成绩不能同时既作为生成反馈的依据、又作为没有新学习的证明。需要不同题组或独立迁移任务，避免答案记忆和训练测试重叠。

## 4. 诊断操纵要符合它实际是什么

可先使用明确告知的模拟岗位和概率性反馈，把“信号可能不准”写入任务规则。不能将随机分配的消息冒充对真实职业能力的准确诊断。正式参与者研究、相应伦理与预注册由团队另行落实；本轮没有发出消息或招募。

若真实系统的自我信息与AI信息相关，应测量或建模这种相关性，而不是直接套用v2的条件独立设定。若人已经很了解自己，AI没有额外作用也是有效的否定性结果。

## 5. 估计与解释

主要比较随机分组的ITT及诊断×V入口交互。处理前能力/信念的异质性可预先规定；不以处理后的信念或行动分组直接替代随机比较。

先检验诊断是否改变信念及行动，再讨论独立学习结果。中介路径的因果识别需要额外假设或操纵，不能仅凭回归加入中介就称机制证实。

样本量需要结合可招募人数、最小有意义变化、测量误差与不确定性要求另作设计；不能从320格模拟倒推真实样本人数，也不凭空指定“足够发表”的N。

## 6. 继续与停止的门槛

| 观察/条件 | 建议 |
|---|---|
| 没有独立验证路径或组织不接受其证据 | 修改现实情境；不要靠模型假设填补 |
| 候选人已有足够信息，诊断既不更新信念也不改变行为 | 不以提高诊断准确率作为主机制 |
| 诊断改变信念，但没有可行行动可承接 | 考虑机会制度问题；先核实资源和规则，不直接堆参数 |
| 只看到便宜路线更受欢迎，没有额外理论预测 | 保留为应用/设计证据，不宣称组织理论新贡献 |
| 总体培训比例不变，但能力不同者改变了不同动作 | 继续检验学习与证明的分流，平均次数不足以否定机制 |
| 能明确识别信息与行动资格的不同效果，并与既有理论产生条件冲突 | 再讨论是否建立更完整组织模型或修订proposal |

最后一项依然需要新的文献对话与解释，不能仅凭一个显著交互就确认理论空白。
