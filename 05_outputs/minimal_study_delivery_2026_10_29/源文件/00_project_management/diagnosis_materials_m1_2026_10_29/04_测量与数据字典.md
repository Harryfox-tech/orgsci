# 测量与数据字段：不要把动作、记录和能力混为一列

本文件定义未来数据结构，没有生成真实受试者数据。程序中的示例答案是人工固定夹具。

## 1. 最低字段

| 字段 | 含义与记录规则 |
|---|---|
| participant_id | 将来采用匿名研究编号；本轮无真实ID |
| material_version | M1；内容或评分变化需换版本 |
| feedback_arm / verification_access | 随机处理；不按事后行动重命名组别 |
| prior_experience | 基线经验，测量方式待试做 |
| belief_before_A / belief_after_A_before_feedback / belief_after_feedback | 自我判断的三个时间点；不是客观准确率r |
| A_response_status / A_score / A_item_checks | 基线作答完整度、原始分与项目结果；不等于真实K |
| chosen_action / started_action / completed_action | L、V、N；分别记录选择、开始和完成 |
| learning_time / verification_time / outside_learning | 实际投入；空值不能自动变0 |
| B_response_status / B_score / B_item_checks | 两条路径相同的认可测评 |
| recognized_pass / verified_domains | 只由B按固定规则产生；不从A/C补齐 |
| C_response_status / C_score / C_item_checks | 所有人都受邀的独立后测；缺失单列 |
| comprehension / suspected_purpose / exit_reason | 操作理解与流失原因；不自动删掉不符合预期者 |

这些字段不是要求一次询问大量问卷。正式任务需精简、检查重复提问是否改变行为，并在接触数据前确定主次。

## 2. 主要比较

验证开放条件内，C11与C01比较实际选择V的ITT差异，是最直接的行动重排检查。学习与退出同时报告，不能只报告显著的一项。

关键结果是各随机组的同一C表现，以及另列的B认可记录。不能只比较自选V者与自选L者后宣称验证的因果效应。A可用于事前规定的调整和异质性，不按处理后信心或B通过结果制造组别。

四格交互仍见[前轮规格](../diagnosis_institution_check_2026_10_29/03_独立机制实验准备稿.md)。V入口关闭时V使用为零是制度事实；仅该交互显著不构成能力形成机制的证明。

## 3. 缺失与比较性

- N是退出发展/认可路径，不等于退出研究；仍邀请C。
- 没有参加B，与参加B未通过不同；两者也不等于“没有能力”。
- 未完成C应记录原因和缺失，预先安排各组相同的后测激励与邀请方式。
- 不能用C−A的裸差冒充已校准增长；A/C内容不同，先检查比较性。
- 重复尝试、答案泄漏和外部工具使用规则需事先明确，不能事后只约束某一组。

## 4. 样本与分析尚未确定

未确定人数、补偿、最小有意义变化、时长、主要模型、流失处理或多重比较规则。没有数据可做功效估计，本轮不编造“足以发表”的样本数。

内部试做首先检验理解、时间、地板/天花板和学习材料是否有用；正式统计计划根据这些条件另定，不能从22项程序检查或320格模型倒推受试者人数。
